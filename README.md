# Mufa Colony
Game #3 Mufa Games. Simulasi, strategi, manajemen sumber daya. HTML/CSS/JS murni, tanpa aset eksternal.

## Menjalankan
Buka `index.html` di browser (atau host statis). Tidak perlu server.
